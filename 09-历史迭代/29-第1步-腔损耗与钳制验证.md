# 第 1 步：腔损耗与增益钳制验证（含一个重要反转）

> 2026-10-09。目标是给设计加腔损耗参数、让自洽增益成为阈值判据。过程中发现了三个关键事实，其中最后一个修正了我此前的判断。

## 1. 三个工具层面的发现

### 1.1 `CavityLosses` / `OverlapFactor` 单独加无效

在 Gain 块里加上 `CavityLosses = 5`、`OverlapFactor = 0.5` 后重跑，输出与不加时**逐字节相同**（SHA256 一致）：

```
无损耗版 hash: 4ACE4DB856174AEAD214AFEB998314BF6F40E3DC41190ED1BCE0FCA1C5DEE560
有损耗版 hash: 4ACE4DB856174AEAD214AFEB998314BF6F40E3DC41190ED1BCE0FCA1C5DEE560
```

结论：这两个参数**只在开启 `GainClamping = yes` 时才起作用**。

### 1.2 `GainClamping = yes` 必须配套 `EMfield{ EMmode{} }`

只加 `GainClamping = yes` 会让可执行文件**崩溃**（exit code 0xC0000005 访问冲突，发生在第一次迭代）。

查阅官方示例后确认：所有用 `GainClamping = yes` 的示例都同时提供

```python
EMfield{
    EMmode{
        PhotonEnergy = 156      # 目标光子能量 [meV]
        ElectricField = 0.0
    }
}
```

补上之后运行正常。**这是一个值得记住的踩坑点。**

### 1.3 钳制路径本身可靠（用两个已知能激射的对照验证）

| 对照 | 模态增益 | 腔损耗 | L-I 输出功率 | 判断 |
|---|---|---|---|---|
| 官方 Bai 钳制示例 @320 mV, 100 K | **2.79999** cm⁻¹ | 2.8 | 2.0×10⁸ W/cm³ | 激射 ✓ |
| 官方 Bai 钳制示例 @320 mV, **300 K** | **2.8** cm⁻¹ | 2.8 | 8.0×10⁷ W/cm³ | 激射 ✓ |

模态增益与损耗**精确相等**（钳制条件成立），且输出功率非零。**说明这条自洽计算路径在 100 K 与 300 K 都工作正常。**

## 2. 我们的设计：判定为不激射

在同样的设置下（GainClamping = yes、CavityLosses = 5、OverlapFactor = 0.5、PhotonEnergy = 156 meV），我们的 8 µm 设计在 240 mV/周期给出：

| 量 | 数值 |
|---|---|
| 自洽增益 | **−3.35 cm⁻¹** |
| 模态增益（×0.5） | **−1.68 cm⁻¹** |
| 腔损耗 | 5 cm⁻¹ |
| L-I 输出功率 | ≈ 0 |
| 判定 | **不激射** |

## 3. 必须诚实说明的反转

此前（[[25-第1步-降掺杂重跑结果]]）我根据"官方示例的自洽增益恰好等于其损耗值"推断：自洽增益是"被损耗钳制的量"、而 **FGR（小信号）增益才是材料增益**。

现在有了完整对照，这个判断需要修正为：

- **FGR 增益是小信号上限，不代表可持续的增益**
- **自洽（钳制）计算的模态增益 vs 腔损耗才是激射判据**，且这条路径已被两个已知器件验证可靠
- 我们的设计：FGR 给 +22 cm⁻¹（看着远超阈值），但自洽计算给出负增益 → **这个正增益不可持续**

这也与之前留下的警告吻合：主导跃迁的"增益÷自发光比值"出现符号翻转——它本来就是"该跃迁的增益不可持续"的信号。

## 4. 真正的疑点：模型复现不了 Fei 2021 器件

更关键的是：**我们的模型对未修改的 Fei 2021 原结构同样判定不激射**（自洽增益恒为 −2～−7 cm⁻¹），而那是一个真实的、能在 300 K 连续波工作到 408 K 的器件。

而同一套工作流、同一套散射参数、同样的 300 K 温度下，官方 Bai 结构能正常复现激射。所以：

> **问题不在工作流，而在我们对 Fei 结构的重建**——层序解析、掺杂位置、工作点或材料参数之一有系统性错误。

候选原因（按可疑度排序）：

1. **掺杂位置**：原文用下划线标注掺杂层，该格式在 PDF 中丢失，我们用的是假设位置 [24.8, 33.5] nm。位置错误会直接破坏注入与反转
2. **工作点**：240 mV/周期（41 kV/cm）是按 Fei 结构的周期长度推算的设计场；真实器件阈值工作点可能不同
3. **层序解析**：现有层序来自 PDF 文本提取（粗体已用字体层核对），但"哪一层是垒/阱"以及末尾层是否完整仍值得复核
4. **材料参数**：晶格匹配体系的带阶（0.533 eV）已与文献一致，但有效质量/非抛物性仍有不确定度

## 5. 下一步建议

好消息是**钳制计算现在很快**（官方结构单点约 2 分钟，我们的结构约 10 分钟），所以可以低成本做扫描：

1. **本结构偏压扫描（带钳制）**：在 180 / 200 / 220 / 260 / 280 mV 各跑一点，看**是否存在任何一个偏压给出正模态增益**。若全负，说明结构与掺杂需要改；若有正，就找到了真实工作点
2. **掺杂位置对照**：换一个掺杂区（靠近注入垒的 2.4/2.5/2.3 nm 阱）跑同一点，比较模态增益
3. **层序复核**：回到 PDF 再核一遍 22 层与两个端点层（这一步无需计算，先做）
