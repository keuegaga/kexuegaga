# 模型层面排查：相干长度、能量窗、空间网格

> 2026-10-09。按选项 3 逐个试模型层面的设置。结果：**三项要么直接数值失败，要么不改变结论**。

## 1. 测试一：相干长度 1 → 2（失败）

`CoherenceLengthInPeriods` 从 1 提到 2（官方示例全部用 1，但它们的周期只有 22–43 nm，我们是 57.3 nm，本想让相干处理覆盖更长范围）：

运行在第一次迭代就崩溃：

```
[WARNING] selfEnergies.sigR contains NaN!
NextnanoNEGF::Functions::invertMatrix: Illegal parameter(s) to LAPACKE_zgetrf call!
```

即推迟自能出现 NaN、随后矩阵求逆失败。**该结构在相干长度 2 下无法求解。**

## 2. 测试二：轴向能量窗 500 → 800 meV（失败）

我们结构一个周期内的能级跨度约 460 meV，3 个周期下来阶梯跨度超过 700 meV，因此试把轴向窗从 500 扩到 800 meV：

- 能量网格点从约 360 增到 **532**
- 运行到第 6 次迭代时增益出现 **NaN**

同样数值失败。

## 3. 测试三：空间网格 0.2 → 0.1 nm（无影响）

我们结构里有 0.9 nm 的薄垒，0.2 nm 网格只能解析约 4 个点，怀疑分辨不足，于是把网格细化一倍：

| 网格 | 迭代进度 | 模态增益 @260 mV |
|---|---|---|
| 0.2 nm（原设置） | 收敛 | −1.36 cm⁻¹ |
| **0.1 nm（细化）** | 第 72 次迭代时 | **−1.32 cm⁻¹** |

结果几乎相同——**网格分辨率不是原因**（该运行仍在后台继续，但趋势已明确）。

## 4. 本轮结论

模型层面的三个可调项：

| 调整 | 结果 |
|---|---|
| 相干长度 1 → 2 | ❌ 数值崩溃（NaN + 矩阵求逆失败） |
| 轴向能量窗 500 → 800 | ❌ 数值崩溃（增益 NaN） |
| 空间网格 0.2 → 0.1 nm | ⚪ 可运行，但结论不变（−1.36 → −1.32） |

**即：能收敛的设置都给负增益，想扩大求解范围就会数值失败。**

## 5. 整体诊断的最终状态

到此为止，我们已经系统地排除了：

| 类别 | 项目 | 结论 |
|---|---|---|
| 结构 | 层序解析（字体级核对） | 无误 |
| 结构 | 掺杂位置（两种常见放法） | 无影响 |
| 结构 | 界面渐变（0.3 nm） | 仅 +1.7 meV |
| 结构 | 有源区宽度（±0.3 nm） | 只调波长，不解决激射 |
| 参数 | 导带带阶（0.53 / 0.70 eV） | 无改善 |
| 参数 | 偏压（200–320 mV） | 全为负增益 |
| 数值 | 面内窗/离散、轴向窗、网格、相干长度 | 保守设置可行但无增益；放宽即崩溃 |
| 工具 | 同一工作流跑 3 个官方案例 | 均正确复现激射 |

**唯一稳定的现象**：小信号（FGR）增益恒为正（+5 ～ +35 cm⁻¹），自洽（钳制）增益恒为负（−1 ～ −5 cm⁻¹）。说明在 NEGF 的输运解里这个结构的反转建立不起来。

## 6. 建议

到了这一步，继续自助式试错的边际收益已经很低。建议二选一：

**选项 1（推荐）：向 nextnano 官方技术支持提交案例。**

我们手上有一份信息非常完整的报告：同一流程下 3 个官方案例正常、按文献重建的 Fei 2021 结构在 7 类参数变体下全部不激射，且放宽数值设置会直接崩溃。这类对照正是厂商定位问题最需要的。可一并提交：`designs/fei2021_negf_clamp_biasscan.negf`、`runs/fei2021_negf_clamp_biasscan/`、以及 [[33-参数对照实验-掺杂位置与带阶]] 与本文的排除清单。

**选项 2：改用工作流已验证的材料体系做 8 µm 设计。**

官方示例用的是应变 InGaAs/AlInAs（带阶 0.7–0.8 eV），我们的流程对它验证通过。改用它设计 8 µm QCL，可以把之前所有方法论（材料增益 vs 钳制增益的区分、一致性检查、灵敏度分析）直接搬过来，避免再陷在"复现不了文献结构"的问题里。
