# PICS3D 激光器仿真培训计划

> **终点目标**：能独立设计**高速调制 GaN 激光器芯片**的仿真模型，并让模型对真实实验有指导意义（阈值/波长/功率/带宽与实验可比）。
> **教材**：手上这个 nakamura 案例（结构、求解、后处理、数据全部齐备）+ 官方手册。

## 教学法：四步循环

每个知识点的学法都是同一个循环，**每次只改一个东西**：

```text
读懂一行/一个量  →  先预测改了会怎样  →  真的跑一次  →  读输出验证预测  →  写进笔记
```

我会按"讲义 → 练习 3 题 → 你交结果 → 我判卷并补笔记"的节奏走；笔记都落在本库，形成你自己的可检索知识库。

## M8 高速调制专题（详细拆解）

### M8.1 理论基础
速率方程 → 弛豫振荡频率 `f_r ∝ sqrt(v_g·dΓ/dI·S0/…)`、阻尼（K 因子）→ `f_3dB`、以及 **RC 限制**（串联电阻 × 结电容）。

### M8.2 PICS3D 里怎么做（已查证）

手册第 7 章 *AC ANALYSIS AND HIGH FREQUENCY PARAMETERS*（P127-140）：

> "**The AC analysis is activated by the input file with extension `.plt`.** The input file must specify which data set (thus the DC bias condition) is used for the AC analysis. The statement **`ac_voltage`** is used to apply a 1V AC signal on one of the contacts. The resulting AC current data are stored in an output file… a statement such as **`plot_ac_curr`** is used to [plot it]."

> §7.5 *Laser Diode Modulation Response*：光调制响应是 AC 分析的特例，需要在漂移-扩散方程组上**追加光子速率方程**，用 `ac_voltage` 施加小信号。

相关语句（语句参考）：`ac_light`（§23.20, P501）、`ac_parameters`（§23.21, P502）、`ac_voltage`（§23.22, P505）、`ac_well`（§23.23, P509）。RIN（相对强度噪声）也在手册中（P363/719/943 一带），到时再展开。

**工作流**：先跑完 DC 三段偏置（到目标工作点）→ 再写一个 `ac.plt`，用 `get_data` 选中该偏置点、`ac_voltage` 加小信号、`plot_ac_curr` 出频响 → 从频响里提 `f_3dB`、谐振峰、阻尼。

### M8.3 影响带宽的结构/参数（设计时要盯的）

| 决定带宽的因素 | 对应的结构/仿真参数 | 方向 |
|---|---|---|
| 微分增益 dΓ/dI、有源区体积 | 阱数/阱厚、光限制因子 Γ、腔长 | 阱少/体积小 → dΓ/dI 大 → f_r 高 |
| 光子寿命 τ_p | 腔长、腔面反射率（镀膜） | 腔短/反射低 → τ_p 小 → 带宽高（但阈值升） |
| 结电容 C、串联电阻 R_s | 脊宽、接触面积、pad、掺杂、电流阻挡 | 面积小/掺杂优化 → RC 截止高 |
| 自热与热阻 | 热流模型、衬底、封装（模型里要加自热） | 热阻低 → 大电流下带宽衰减小 |
| 量子阱输运/俘获 | `q_transport`、阱垒结构 | 改善载流子注入 → 抑制阻尼 |
| 内损与阈值 | α_i、α_m | 阈值低 → 同样电流下 f_r 高 |

### M8.4 练习
1. 在 nakamura 的某个偏置点（如 40 mA）跑 AC 响应，提 `f_3dB` 并画出频响；
2. 把脊宽 4 → 2 µm（同时 `mode_num` 降到 1~3），比较 `f_3dB` 与阈值的变化；
3. 加镀膜（前 0.05 / 后 0.95）与加自热两种情形，分别看带宽与功率的取舍。

### M8.5 验收
能对"**结构 → 阈值 / 功率 / 带宽**"给出定量趋势表，并对真实芯片设计提出可执行建议（含工艺约束与代价）。

## 需要你准备的参考资料（M7 开始要用）

- 目标器件的**实验数据**：阈值电流/电流密度、工作电压、输出功率、斜率效率、波长、内损、Γ（若有）
- **结构参数**：层序、组分、厚度、掺杂、脊宽、腔长、腔面镀膜
- **高速指标**：调制带宽/眼图/RC 参数、S21 曲线（若有）
- **工艺约束**：衬底、刻蚀深度、电流阻挡方式、pad 尺寸与封装
- **参考文献原文**（PDF 即可，我会按库规范归档到 `99-原始资料/`）
