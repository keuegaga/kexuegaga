# M1 讲义：结构文件 `.layer` 与 GaN 激光器器件物理

> 面向零基础。读完本讲你要能做到：**看懂一个 `.layer` 文件的每一行、知道每层为什么存在、能安全地改厚度/组分/掺杂/脊宽并正确重新生成网格。**
> 配套练习在最后一节；做完把答案发我，我判卷。

## 0. 先建立物理图像：薄膜堆叠 = 一个"光的管子 + 电的通道"

GaN 激光器本质上是一摞几微米厚的薄膜（总厚约 4~5 µm），从下到上是：

```text
  p 电极  ─────────────┐            ← 电流从这里进
  p 接触层(p-GaN)      │ 电的通道：把空穴送进有源区
  p 包层(AlGaN)        │ 光：折射率低 → 把光"关"在中间
  p 波导(GaN)          │ 光：折射率偏高 → 引导光
  【电子阻挡层 EBL】    │ 电：挡住电子别跑过头
  ─── 有源区 MQW ───   │ 光+电：电子空穴在这里复合发光（3~4 个量子阱）
  n 波导(InGaN)        │ 光：引导光
  n 包层(AlGaN)        │ 光：折射率低 → 限制光
  n 接触层(n-GaN)      │ 电：把电子送进有源区；同时是 n 电极的落脚处
  衬底（本例为蓝宝石）  │ 只做机械支撑，不导电
```

三个基本矛盾决定了所有设计取舍：

1. **光要"关住"**：靠折射率台阶（包层折射率低、波导高）。台阶越小，光越容易漏到接触层/衬底 → 光限制因子 Γ 越小 → 阈值越高。
2. **电要"顺畅"**：掺杂越高电阻越小，但**掺杂会吸收光**（自由载流子吸收）→ 有源区附近要"电顺畅、光干净"，这是矛盾的。
3. **材料要"长得出"**：AlGaN 里 Al 越多，折射率越低（光限制越好），但**越容易开裂、p 型掺杂越难**。本例用 Al 只到 0.08，正是这个矛盾的折中（用 InGaN 波导来补）。

## 1. `.layer` 文件的语法（只有 6 类语句）

| 语句 | 作用 | 本例出现 |
|---|---|---|
| `begin_layer` … `end_layer` | 文件起止 | ✓ |
| `independent_mqw` | 多量子阱**每阱用独立材料号**（GaN 极化器件必需） | ✓ |
| `column column_num=N w=… mesh_num=… r=…` | 定义**横向**分列：宽度、横向网格点数、网格比 | 3 列（4.0 + 0.5 + 0.5 µm） |
| `top_contact column_num=… from=… to=… contact_num=…` | 在某列顶面设**电极**并编号 | 脊顶=p（2 号）、蚀出区=n（1 号） |
| `layer_mater macro_name=… column_num=…` | 给**接下来这一层**指定该列的材料 | ✓ |
| `layer d=… n=… r=… n_doping1=…/p_doping1=…` | **一层**：厚度、纵向网格点数、网格比、各列掺杂 | ✓ |
| `include file=s2.qw / s2.bar` | 把阱/垒定义就地展开（免得写 5 遍） | ✓ |

**单位（最容易出错的地方）**：

| 量 | 文件里的单位 | 换算 |
|---|---|---|
| 厚度 `d`、宽度 `w`、坐标 | **µm** | 1 µm = 1000 nm |
| 掺杂 `n_doping1` / `p_doping1` | **m⁻³** | `5e24 m⁻³ = 5e18 cm⁻³`；`1e26 = 1e20 cm⁻³` |
| 组分 `var1=` | 无量纲（x 值） | `var1=0.15` = In₀.₁₅Ga₀.₈₅N |
| 网格点数 `n` / `mesh_num` | **个数**，不是间距 | 点数越多间距越小 |

**横向结构**：列 2/3 从 n-GaN 之上全是 `air`/`void` → 等效于把两侧**刻蚀到 n-GaN**；于是：

- 脊顶（列 1）放 p 电极（`contact_num=2`）；
- 被蚀出的 n-GaN 顶面（列 3）放 n 电极（`contact_num=1`）。

这就是**蓝宝石衬底激光器的标准做法**（衬底不导电，n 电极只能从上面引出来）。

## 3. 网格：`n`、`r`、`mesh_num` 与 `Total mesh points`

- `.layer` 里 `n=…` 是**该层的纵向网格点数**，`r=` 是网格间距的**渐变比**（负号 = 间距按比例缩小/放大，用来在某一侧加密）。
- 横向密度由 `column … mesh_num=` 决定。
- 运行时日志会打印：

```text
 zsegment       mesh      plane-indexes
  1           8880           1  ->  10
 Total mesh points=       88800
```

本例：**每个 z 平面 8880 点 × 10 个 z 平面 = 88800 点**。

**加密/减密的原则**（手册 §4.5/§4.6）：

| 区域 | 怎么办 | 原因 |
|---|---|---|
| 有源区、异质结界面、量子阱、光场峰值区、电流拥挤区 | **加密** | 这些地方物理量剧变，网格粗了会算不准甚至不收敛 |
| 金属、重掺杂接触区等**低阻区** | **减密** | 电阻小 → ΔV≈0 → ΔI=ΔV/R 数值不稳，反而不收敛 |

## 6. 常见坑（每条都是真实踩过的）

1. **掺杂单位写错**：`.layer` 用 m⁻³。写 `1e18` 意味着 1e12 cm⁻³（几乎不掺杂）；想要 1e18 cm⁻³ 要写 `1e24`。
2. **改了 `.layer` 忘了重跑 `layer.exe`**：求解器还在用旧 `s2.msh`，你会看到"明明改了却没变化"。
3. **只改层厚不改 `top_contact` 的 `from/to`**：脊宽改了但电极还盖在 4 µm 上，电流注入面积就错了。
4. **`r`（网格比）标志弄反**：`r=-1.1` 与 `r=1.1` 的加密方向相反，界面附近的精度会差很多。
5. **p/n 弄反**：从下往上是 n → p；`n_doping` 出现在上半部分就要警觉。
6. **`include file=s2.qw/s2.bar` 被误删**：MQW 就没了，只剩一个厚垒。
7. **`.layer` 存成 UTF-8 无 BOM 且带中文注释**：SimuPics3d 里会显示成乱码（编码规范见 [[00-入口/知识库规范]]）。

### M1-1 标准答案（你答对了，补上完整链条）

抑 QCSE 的**唯一关键手法**：**垒用 In₀.₀₂GaN 而不是纯 GaN**。

```text
阱 In0.15GaN  ←→  垒 In0.02GaN      阱垒 In 差 = 0.13  →  失配应变小
阱 In0.15GaN  ←→  垒 GaN（传统做法） 阱垒 In 差 = 0.15  →  应变大
→ 应变小 ⇒ 压电极化电荷少 ⇒ 量子阱里的内建电场弱 ⇒ 能带倾斜小 ⇒ 电子/空穴波函数重叠好
→ 发光峰蓝移回收、阈值下降、微分增益上升（对高速调制尤其重要）
```

**容易误判的三处**（都不是为 QCSE 服务的）：

- 第 3–4 层 InGaN 波导 → 作用是把**光**兜住（低 Al 包层不够，用高折射率 InGaN 补），是**光限制**手段；
- 第 13–14 层界面渐变 → 作用是**削掉价带尖峰、降低开启电压**，是**电学**手段；
- EBL（Al₀.₂GaN，10 nm）→ 作用是**挡电子**、压漏电。

### M1-3 标准答案（这题是本轮最大的知识漏洞）

**你的答案错在把"电压"和"阈值"混成一件事。**正确分解：

| 影响路径 | 结果 | 量级 |
|---|---|---|
| p 接触层 1e20 → 1e19 cm⁻³ ⇒ **欧姆接触/串联电阻升高** | 工作电压升高（`V = V_j + I·R_s`） | **主效应，明显** |
| 阈值电流 `I_th` | **基本不变** | 很小 |
| 经自热间接影响（大电流下） | 焦耳热 ↑ → 结温 ↑ → 增益峰红移、`I_th` 升、`η_d` 降 | 中等（模型带 `heat_flow` 时才体现） |

**为什么阈值几乎不动**：阈值由"有源区载流子密度到达 增益 = 总损耗"决定；接触层远离有源区，不参与这个平衡。串联电阻只"吃掉"电压，不"吃掉"电流（电流仍全部流过有源区）。

> **一句话记法：电阻管电压，损耗管阈值。**

**真正能显著改 `I_th` 的是有源区/光场附近的损耗或复合**，这也正是本例的掺杂布局逻辑：

- p 包层只给 `p_doping=5e25`（5e19 cm⁻³）、n 包层给 `1e24`（1e18 cm⁻³）→ 减少**自由载流子吸收**；
- n 侧间隔层给 `5e23`（5e17 cm⁻³）→ 有源区附近刻意低掺杂；
- 由 M7-A 的结论：**α_i ↓ ⇒ 总损耗 ↓ ⇒ I_th ↓ 且 η_i ↑**（η_i 是总损耗的函数）。

### M1-5 标准答案（你答对了，但有坑）

✅ **不需要重跑 `layer.exe`**（`.layer` 和网格都没动）；
✅ **可以 `restart`**（restart 的硬约束只有一条：**网格/结构不能变**）。

但有 3 个必须知道的注意点：

1. **旧数据集的光学量与新设置不可比**：`wavel_range` 一变，λ/增益谱/模场都变了，**不要拿旧数据集的 λ、增益去和新的混着画图或算 `η_d`**；
2. **`prn.gain_num` 是波长格点数**（本例 100）。如果你把它也改了，**光学数组尺寸变了**，旧数据集载入可能出问题 → 保守做法是**从头跑**，或把 restart 起点选在光学量即将被重算的数据集；
3. **窗口必须罩住激射波长**（本例 423~425 nm）。若把上界压到 0.42 µm 以下，就会看不到激射峰，得到"没有增益"的假象。本例 `wavel_range=[0.36 0.44]` ✓ 安全。

判据：续算后日志无载入错误，且 `.sol.msg` 里报的波长落在新窗口内。

### 本轮暴露的 3 个学习点（写进你的肌肉记忆）

1. **行号/字段一律以打开的文件为准**——讲义表格序号 ≠ 文件行号；
2. **"电阻"与"损耗"分开**：电阻 → 电压；损耗 → 阈值与效率；
3. **网格点数不靠猜**——改完 `.layer` 必重跑 `layer.exe` + `pics3d s2.geo`，读日志里的 `Total mesh points`。
