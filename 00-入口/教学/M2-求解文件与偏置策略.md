# M2 讲义：求解文件 `.sol` 与三段偏置策略

> **目标**：能**从零写出一个能跑通的 `.sol`**，并解释每一句的作用；理解 `equilibrium → rtgain_phase → scan×3` 各段在干什么、靠什么条件停。
> **配套**：[[06-案例/nakamura-sol逐行注释]]（同一文件的逐行注释版，可对照看）。练习在最后一节，做完发我判卷。

## 0. 三个文件的分工（先分清，不然会互相打架）

| 文件 | 回答什么问题 | 谁生成 |
|---|---|---|
| `.layer`（+ `s2.qw`/`s2.bar`） | 器件**长什么样**：层序、组分、厚度、掺杂、脊宽、横向列、网格点数 | 你手写 |
| `s2.geo` / `s2.mater` / `s2.doping` / `s2.msh` | 几何、材料表、掺杂分布、**网格** | `layer.exe` → `pics3d.exe s2.geo` 生成，**你不动** |
| **`.sol`** | **怎么算**：加载哪个网格、开哪些物理模型、光学窗口多大、Newton 参数、**偏置流程** | 你手写 |

**铁律**：改 `.layer` → 必须重跑 `layer.exe` + `pics3d s2.geo`，且**不能 restart**；只改 `.sol` 里与网格无关的设置 → 可以 restart（详见 [[04-操作流程/PICS3D中断续算]]）。

## 1. 骨架：只有两个 `begin … end`

```text
begin               ← 主段（结构、物理模型、光学、求解器、偏置流程）
   ...
end

begin_zsol          ← 纵向（腔方向）设置段（端面反射率、纵向分段、横向模式）
   ...
end_zsol
```

> 注意：`.sol` **没有** `begin_sol`，主段直接写 `begin`。文件里 `$` 开头是注释；一条语句没写完可以用行尾 `&&` 续行（本例到处都是）。

## 3. 核心：三段偏置到底在干什么

```text
equilibrium                                   ← ① 零偏置平衡态
rtgain_phase density=2.e25                    ← 用固定载流子密度先算一遍往返增益谱（给光学打底）
scan var=current_1 value_to=1e-3              ← ② 爬到 1 mA
scan var=current_1 value_to=100e-3 &&
     auto_finish=rtgain auto_until=0.6 …      ← ③ 一直爬到"RTG 裕度 = 0.6"就停（不看电流值！）
scan var=current_1 value_to=60e-3 &&
     solve_rtg=yes                            ← ④ 真正开 RTG 求解，爬到 60 mA
```

对应的 4 个数据集（`s2.std_0001…0004` / `s2.out_0001…0004`）：

| 数据集 | 来源                               | 典型值（R=0.5，轻量版实测）                 |
| --- | -------------------------------- | -------------------------------- |
| #1  | `equilibrium`                    | I = 0 mA，V = 0                   |
| #2  | 第 1 段 scan                       | I = 1 mA，V = −3.467 V            |
| #3  | 第 2 段 scan（`auto_finish=rtgain`） | **I = 21.49 mA**（**不是** 100 mA！） |
| #4  | 第 3 段 scan（`solve_rtg=yes`）      | I = 60 mA，双端面 23.15 mW           |

**四个必须理解的点**：

1. **`rtgain_phase`**：先用一个固定载流子密度（`density=2.e25`）算一遍增益谱，让光学求解器有初值。它不产生数据集。
2. **`auto_finish=rtgain auto_until=0.6 auto_within=0.1`**：第 2 段的停止条件是**往返增益裕度到 0.6**，`value_to=100e-3` 只是"上限保险"。
   实测（M7-A）：四个不同腔长的算例都在 **J ≈ 977 ± 8 A/cm²** 处停（±1 %），而改变镜面/内部损耗时停止点会明显移动 —— 详见 **4.1 节**。它只是"离阈值还有一段距离"的初始化点，**不能当成"距阈值的相对位置"**。
3. **`solve_rtg=yes`**：只有第 3 段才真正把 RTG（增益/模式）纳入求解 —— **只有这一段才算"激光"**。前两段是"亚阈值点灯"。
4. **`print_step`** 决定**每多少偏置量落一个数据集**（本例 50e-3 = 每 50 mA 一个），它直接决定数据集个数，而 `restart data_set=N` 的编号又依赖数据集个数 —— 改动 `print_step` 时两者要一起想。

> 实测补充（ai26 判决实验）：把 `init_wave backg_loss` 从 1300 改成 2600（α_i 13→26 /cm），
> 第 2 段的停止点电流从 21.49 → 24.62 mA（+14.6 %），与 `exp(Δα_i/(Γg₀))` 预测的 +15.4 % 吻合。
> **说明改任何损耗/材料参数后，这个"自动停止点"会跟着移动**，不能拿新旧算例的 DS3 直接比较。

## 4. 参数速查（含约束与踩过的坑）

### 4.1 补充讲义：RTG 裕度到底是什么（2026-09-20）

**定义（手册原文）**

> *"By default, PICS3D uses the cavity round-trip gain and solves a complex equation for **unity gain and phase matching: RTG = 1+0i**."*

```text
|RTG| = R1*R2 * exp( 2*L*(Gamma*g - alpha_i) )
        ^^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
       两端面反射率      光在腔里走一个来回的净放大
                        （Gamma*g = 模增益, alpha_i = 内部损耗）

阈值条件： |RTG| = 1   <=>   Gamma*g_th = alpha_i + alpha_m
        alpha_m = (1/2L)*ln(1/(R1*R2))        （镜面损耗）
```

- RTG 是**复数**：**幅度**管"增益够不够"，**相位**管"波长对不对"；
- **RTG = 1 就是阈值**（增益正好抵消 内部损耗 + 镜面损耗，同时满足相位匹配）；
- `auto_until=0.6` = 把往返增益推到**阈值的 60 %** 就结束这段初始化扫描。

**为什么要停在阈值以下（这才是 0.6 的用处）**

第 2 段扫描跑的时候，求解器**还没打开完整的 RTG 光耦合**（`solve_rtg=yes` 才打开）。
如果在这一段直接把总线冲过阈值，光子数会从一个很差的初值突然暴涨，第 3 段的激光求解极难收敛。
停在 0.6 相当于把器件"点到快亮、还没亮"，给第 3 段一个极好的初值。

**`auto_within=0.1` 是容差带**：目标 0.6 ± 0.1（0.5~0.7 都算达标）。日志里能直接看到它的运作：

```text
Eff.cavity.len= 0.549930E+03    1
 Exceeding auto_finish limit.          <- 这一步冲过了容差带上限
   Try again with smaller step.        <- 自动把电流步长减半重试
...
 Eff.cavity.len= 0.549930E+03    1
 Within auto_finish limit.             <- 落入 0.5~0.7 带内
   Let us finish this scan statement.  <- 本段扫描结束，打印 Data set #3
```

（本例实测：步长 1.125 mA 时 `Exceeding`，降到 0.5 mA 后 `Within`。）

**实测：停止点会随损耗移动（这就是它的可操作含义）**

| 实验 | 改了什么 | 总损耗变化 | DS3 停止点 I | 换算电流密度 J |
|---|---|---|---|---|
| R 系列 | R 0.2 → 0.7（L 固定 550 µm） | α_m 29.3 → 6.5 /cm | 26.49 → 19.62 mA | **1204 → 892 A/cm²** |
| ai26 | α_i 13 → 26 /cm | +13 /cm | 21.49 → 24.62 mA | **977 → 1119 A/cm²（+14.6 %）** |
| L 系列 | L 300 → 1200 µm（R 固定 0.5） | α_m 23.1 → 5.78 /cm | I ∝ L | **J ≈ 977 ± 8 A/cm²（几乎不变）** |

三条读法：

1. **损耗越大 → 需要越多增益 → 停止点电流越大**（R 系列、ai26 都严格符合；ai26 的 +14.6 % 还与 `exp(Δα_i/Γg₀)` 的预测 +15.4 % 吻合）；
2. **绝对不要**拿 DS3 的电流当"阈值"或"距阈值的相对位置"——它只是 RTG 意义下的 60 % 点；任何损耗/材料改动都会让它移动；
3. ⚠️ **一个仍未闭合的细节**：L 系列改了腔长后，所需增益理论上应随 1/L 变化，实测 J 却几乎不变。最可能的原因是 (a) RTG 里还含**光子耦合与自发辐射项**（手册对 `cavity_rtg_amplitude` 正是这样定义的），(b) L 系列同时改了 `init_wave length`，而 `zplanes` 固定在 3 造成纵向离散。**不影响 M2 的用法**，但提醒：RTG 裕度不能精确换算成"增益差 / 电流差"。

**想亲眼看 RTG 曲线**：手册 §23.335 确认 `gain_spectrum` 支持 `variable=cavity_rtg_amplitude`。在 `.plt` 里加：

```text
begin_pstprc
get_data main_input=s2.sol sol_inf=s2.out xy_data=(1 4)
gain_spectrum variable=cavity_rtg_amplitude data_file=rtg.csv
end_pstprc
```

就能把 4 个偏置点的 RTG 谱连同数值一起导出（`data_file=` 给 CSV，方便自己画图）。

**三个常见误解**

1. ❌ "0.6 是 60 % 的电流 / 功率" → 是 **RTG 幅度**的 60 %；
2. ❌ "`auto_until` 越大越省事" → 越大越接近阈值，第 3 段越危险（可能直接越过阈值导致不收敛）；
3. ❌ "DS3 就是阈值" → DS3 在阈值**以下**；真阈值要用 L-I 外推（见 [[04-操作流程/激光器阈值判定与L-I分析]]）。

### ① 控制与输入

| 语句 | 含义 | 典型值 | 约束 / 坑 |
|---|---|---|---|
| `3d_solution_method 3d_flow=yes z_connect=no` | 三维电流流动的开法 | 本例此值 | 与 z 方向网格（`zplanes`）配合；改法会影响收敛 |
| `z_structure uniform_length=550 zseg_num=1 zplanes=3` | 腔长 550 µm、**纵向 z 平面数 3** | 轻量版 3 / 正式版 10 | ⚠️ `zplanes` 太粗会让纵向量的**离散误差**混进结果（M7-A 第一版就是这样失败的）；**正式数据用 10** |

| `include file=s2.gain` / `s2.doping` | 载入增益文件与掺杂分布 | — | 由 `layer.exe` 生成；文件缺失/0 字节 → 直接报错 |
| `output sol_outf=s2.out` | 输出基名 | s2.out | 数据集就是 `s2.out_0001…`、`s2.std_0001…` |

### ② 物理模型开关

| 语句 | 含义 | 约束 / 坑 |
|---|---|---|
| `polarization_charge_model screening=0.5` | 自发+压电极化电荷模型，屏蔽因子 0.5 | **GaN/InGaN 器件必需**，去掉会得到完全错的阈值 |
| `self_consistent` | 量子阱与极化自洽求解 | 与 `set_active_reg` 的 `valence_mixing` 配合 |
| `q_transport` | 量子阱载流子输运 | ⚠️ **缺了它会报 `---q-tunneling/transport option required.`**（本库实测踩过） |
| `temperature temp=293.` | 晶格温度 293 K | 与材料宏的温度系数不匹配 → 带隙/增益偏差 |
| `set_active_reg tau_scat=1.e-13 valence_mixing=no mode=te gain_coulomb=no bandgap_renorm=no diel_av=9.5` | 有源区参数：散射时间、价带混合、偏振、库仑增益增强、带隙重整、介电常数 | `valence_mixing=no` 是本例设定；开启它会显著增加计算量 |

### ③ 光学设置

| 语句                                                                       | 含义                                         | 约束 / 坑                                              |
| ------------------------------------------------------------------------ | ------------------------------------------ | --------------------------------------------------- |
| `wave_boundary point_ll=[0.0 3.4] point_ur=[4.5 4.4]`                    | **光场计算窗口**的两个角点（µm）                        | 窗口必须**罩住整个外延层**（本例层顶到 4.6 µm），否则光场被截断、Γ 算错          |
| `init_wave backg_loss=1300.`                                             | 内部损耗 α_i = 1300 /m = **13.0 /cm**（单位 m⁻¹！） | 详见 [[05-API与命令/核心参数]] 的 `backg_loss` 条目；改它必须重扫偏置    |
| `init_wave init_wavel=.42`                                               | 参考波长 0.42 µm                               | —                                                   |
| `init_wave wavel_range=[0.36 0.44] prn.gain_num=100`                     | 波长窗口 360–440 nm，**100 个波长格点**              | ⚠️ 窗口必须罩住激射波长（本例 423~425 nm）；改 `gain_num` 会改变光学数组尺寸 |
| `direct_eigen`                                                           | 用直接本征求解器解横向模式                              | 与 `multimode` 配合                                    |
| `multimode mode_num=3 boundary_type1=(2 1 1 1) boundary_type2=(1 1 1 1)` | 同时解 3 个横向/纵向模式                             | `mode_num` 越大越慢；只关心基模时可降到 1                         |

### ④ 求解器参数（两套，别用错段）

| 段落      | 参数                                                                                                                  | 值   | 说明                                         |
| ------- | ------------------------------------------------------------------------------------------------------------------- | --- | ------------------------------------------ |
| 平衡态/初始化 | `newton_par damping_step=5000. max_iter=250 var_tol=1e-4 res_tol=1e-4 print_flag=3 stop_iter=100`                   | 大阻尼 | 平衡态本身好收敛，用大阻尼快速压住初值误差                      |
| 偏置扫描    | `newton_par damping_step=1. var_tol=1e-4 res_tol=1e-4 max_iter=50 stop_iter=30 step_decrease=0.1 step_increase=1.5` | 小阻尼 | **阻尼越小越精确但越慢**；本例 `damping_step=1`（即基本不压步） |

> 相关错误：偏置段沿用 `damping_step=5000` → 收敛慢或停在错解；不收敛时的系统排查见 [[07-故障排查/不收敛]]。

## 5. 常见坑（每条都在本案例真实出现过）

1. **漏 `q_transport`** → 报 `---q-tunneling/transport option required.`；
2. **`load_mesh` 指向过期的 `.msh`**（改了 `.layer` 没重跑 `pics3d s2.geo`）→ "明明改了却没变化"；
3. **改了结构还 `restart`** → 旧数据载入失效或结果不可信；
4. **`wavel_range` 不罩住激射波长** → 看不到增益峰、判错阈值与波长；
5. **`zplanes` 太粗**（如 3）**用于正式数据** → 纵向离散误差（M7-A 第一版的教训：变腔长时四组结果与物理相反）；
6. **`print_step` 与 `restart data_set` 不匹配** → 从错误的数据集续算；
7. **`backg_loss` 单位写成 1/cm** → 损耗小 100 倍、阈值虚低；
8. **文件编码**：`.sol` 里写中文注释要用 **GBK 或 ASCII**，UTF-8 无 BOM 在 SimuPics3d 里会乱码（见 [[00-入口/知识库规范]]）。
