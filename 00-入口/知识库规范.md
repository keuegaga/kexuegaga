# 知识库规范

## Frontmatter

新建笔记使用以下字段：

| 字段 | 说明 |
|---|---|
| `title` | 笔记标题 |
| `type` | index / concept / workflow / parameter / example / validation / troubleshooting / history |
| `product` | nextnano / nextnano.NEGF / literature |
| `version` | 软件版本或文献年份 |
| `status` | draft / source / verified / deprecated / conflict |
| `source` | 输入文件、文献或数据路径 |
| `last_verified` | 最近核对日期 |
| `tags` | 检索标签 |

## 结论可信度

| 状态 | 含义 |
|---|---|
| `source` | 只依据文献或官方文档整理 |
| `verified` | 已由本机计算、文件或实验数据复核 |
| `draft` | 尚未完成验证 |
| `conflict` | 不同模型或文献存在冲突 |
| `deprecated` | 历史路线，不得作为当前依据 |

## 设计判据

“可激射”至少同时满足：

1. 目标波长处材料增益为正；
2. 目标波长是受限谱窗中的全局或可选择的合法峰；
3. 模型增益超过波导、镜面和背景损耗；
4. 阈值电流和电压量级合理；
5. 对层厚、组分、散射和偏压扰动不脆弱；
6. 有独立模型、文献实验或实验表征作为外部验证。

只满足第1项只能标记为“有正增益通道”，不能标记“结构可用”。

## 文件约定

- nextnano 输入：`designs/*.nnp`、`designs/*.negf`
- nextnano 原始输出：`runs/`，通常不入 Git
- 可提交结果：`results/` 下的 CSV、摘要和图
- 可复现分析：`scripts/*.py`
- 原始文献：`QCL_references/` 或 `99-原始资料/`
- Obsidian 附件：`attachments/`
