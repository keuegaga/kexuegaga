# Sun2022 10.33 µm 七项深度验证与外延方案

## 1. 结论先行

当前模型支持：

```text
继续开展 10.2–10.8 µm 长波方向的验证型外延片
```

暂不支持：

```text
直接冻结并量产一个“必然在 10.33 µm 激射”的 DFB 外延片
```

原因不是波长通道不存在，而是多周期相干长度测试出现了严重不一致：

- 1 周期模型给出强激射；
- 2 周期计算变为高电流、高电子温度且负增益/零光场；
- 3 周期计算在第一次 NEGF 迭代即出现 NaN 和 LAPACK 矩阵分解失败。

因此下一步应定义为 **校准/验证片**，而不是最终产品片。

## 3. LDOS 与载流子占据联合判读

![[results/sun2022_deep_validation/ldos_vs_occupancy_216p384mV.png]]

左图是 LDOS，回答“哪些态存在”；右图是能量分辨载流子密度，
回答“哪些态实际被占据”。

判读激射时不能只看 LDOS 亮斑，而应检查：

1. 上态流形 S6/S7 是否被注入；
2. 下态流形 S8/S9 是否被有效抽取；
3. 对应能量间隔是否接近120 meV；
4. 固定光模下是否出现自持光场；
5. 光场是否引起来自上态的受激复合消耗。

216.384 mV 下，S6/S7 上态流形总占据约0.2035，S8/S9 下态
流形约0.1315，流形差约0.0720。该差值低于9.17 µm模式，不是
因为10.33 µm激射更弱，而是因为更强光场把上态消耗到了更低的
钳制值。

## 5. 模式竞争

![[results/sun2022_deep_validation/mode_competition.png]]

216.384 mV 下比较固定光模：

| 波长 | 光子能量 | J (kA/cm²) | 净内部光功率 | 内部WPE |
|---:|---:|---:|---:|---:|
| 9.17 µm | 135.26 meV | 2.578 | 3.09 kW/cm³ | 0.0025% |
| 9.92 µm | 125 meV | 2.805 | 4.008 MW/cm³ | 2.97% |
| 10.16 µm | 122 meV | 2.865 | 4.514 MW/cm³ | 3.28% |
| 10.33 µm | 120 meV | 2.873 | 4.521 MW/cm³ | 3.28% |
| 10.78 µm | 115 meV | 2.911 | 4.965 MW/cm³ | 3.55% |

结果：

- 10.16、10.33、10.78 µm 构成一个宽而平坦的高性能窗口；
- 单点动态输出以10.78 µm略高；
- 细增益峰位于122 meV，即10.16 µm；
- 9.17 µm明显处于强失配区。

因此10.33 µm可作为中心设计值，但DFB应保留约±0.2 µm以上的模式调谐余量。

![[results/sun2022_deep_validation/tolerance_sensitivity.png]]

所有扫描均在48 kV/cm对应偏压、无光场条件下提取120 meV增益：

|---|---:|---:|---:|
| 基线 | 2.578 | 9.93 cm⁻¹ | 100% |
| 全部阱 −0.1 nm | 2.665 | 9.58 | 96% |
| 全部阱 +0.1 nm | 2.756 | 11.16 | 112% |
| 全部垒 −0.1 nm | 2.793 | 9.64 | 97% |
| 全部垒 +0.1 nm | 2.528 | 9.64 | 97% |
| 组分 −0.01 | 2.512 | 9.27 | 93% |
| 组分 +0.01 | 2.742 | 10.40 | 105% |
| 掺杂 −20% | 2.051 | 8.00 | 81% |
| 掺杂 +20% | 3.131 | 11.81 | 119% |
| IFR 0.12 nm | 2.838 | 6.52 | 66% |
| alloy=0.04 | 2.397 | 11.48 | 116% |
| alloy=0.08 | 2.718 | 8.60 | 87% |

单因素层面均未跌破3.19 cm⁻¹材料阈值；最敏感项为：

1. 高IFR；
2. 掺杂不足；
3. 合金散射增强。

因此工艺窗口应重点控制界面粗糙度、实际掺杂和合金无序，
而不是只追求层厚名义值。

## 8. 多周期相干长度：当前模型仍未通过

![[results/sun2022_deep_validation/coherence_sensitivity.png]]

结果：

| 相干长度 | J | 120 meV增益 | 状态 |
|---:|---:|---:|---|
| 1 period | 2.578 kA/cm² | +9.93 cm⁻¹ | 强增益/激射 |
| 2 periods | 6.337 kA/cm² | −12.11 cm⁻¹ | 负增益、零腔场；输出阶段内存不足 |
| 2 periods, reduced output | — | — | 降低输出后仍在第0次迭代出现NaN/LAPACK失败 |
| 3 periods | — | — | 第一次迭代NaN/LAPACK失败 |

这是目前最大的可靠性风险。它可能来自：

- 多周期边界和能量窗口不匹配；
- 当前3-band近似的数值稳定性；
- 相干输运与强光学场耦合导致矩阵病态；
- 单周期模型高估了注入效率和增益。

在 nextnano 支持确认多周期设置前，不能把10.33 µm的强光场结果当作
最终外延签核。

需要特别区分两类失败：2周期“全输出”算例已经计算到电子状态和负增益，
但在写增益/L-I文件时内存不足；随后降低输出量的重试却连第0次NEGF
迭代都未通过。这说明多周期问题不能只用“输出文件太大”解释，仍存在
边界/能量窗或矩阵病态风险。详细日志见
`runs/sun2022_mocvd/sun2022_coherence_2p_reduced.stdout.log`。

## 9. 散射与寿命

![[results/sun2022_deep_validation/scattering_lifetime.png]]

- S6寿命≈0.268 ps；
- S7寿命≈0.121 ps；
- S8寿命≈0.103 ps；
- S9寿命≈0.135 ps；
- LO声子是1–6 ps⁻¹尺度；
- IFR在部分下态/近邻态达到3–4 ps⁻¹；

5–17倍。即使 alloy=0.06已对应较合理的散射势绝对值，寿命失配仍是
外延定量预测的主要不确定度。

## 11. 更可靠的外延片方案

### 11.1 建议采用“两段式”而非直接量产DFB

第一片定义为 **材料与波长校准片**：

```text
InP substrate: n ≈ 2e17 cm^-3
lower InP cladding: 3.4 µm, n ≈ 2.2e16 cm^-3
active core: 50 × [2.8 B / 3.0 W / 1.25 B / 6.27 W /
             1.0 B / 5.35 W / 0.88 B / 4.85 W /
             1.09 B / 4.16 W / 1.22 B / 3.66 W /
             1.42 B / 3.15 W / 1.68 B / 3.3 W]
upper InP cladding: 3.4 µm, n ≈ 2.2e16 cm^-3
InP cap: 0.6 µm, n ≈ 5e18 cm^-3
```

其中：

- W = In₀.₅₉₃Ga₀.₄₀₇As；
- B = Al₀.₆₃₈In₀.₃₆₂As；
- 第13–14层为Si掺杂区，1.5×10¹⁷ cm⁻³；
- 每周期等效掺杂片密度约6.86×10¹⁰ cm⁻²。

首片保留宽区/无光栅测试结构，用于测量EL峰、增益谱、
阈值电流、内损耗和温漂。不要在没有多周期验证前直接锁定DFB。

### 11.2 第二片再制作DFB

暂定DFB参数：

```text
中心波长: 10.33 µm（覆盖10.16–10.78 µm高增益平台）
n_eff: 3.277
一级Bragg周期: 1.576 µm
腔长: 4 mm
目标κL: 1–2
目标κ: 2.5–5 cm^-1
相移: 1/4波长
```

优先尝试侧向耦合或浅刻蚀包层光栅；不要直接深刻蚀有源区，
以免额外引入损耗与非辐射复合。

### 11.3 工艺验收阈值

建议在HRXRD/PL/EL/器件测试中设以下门槛：

- HRXRD周期：45.08 nm，目标偏差≤0.1 nm；
- 全部阱厚偏差：≤±0.1 nm；
- 垒厚偏差：≤±0.1 nm；
- Al/In组分偏差：≤±0.01；
- 掺杂偏离：≤±20%；
- IFR目标：Δ≤0.08 nm，若达到0.12 nm则增益下降约34%；
- EL峰：优先确认10.16–10.33 µm，而不是只接受9.17 µm；
- 阈值和WPE：先用实际腔长/损耗重新换算，再决定是否进入DFB流片。

## 12. 当前是否可以制作外延片

| 决策 | 结论 |
|---|---|
| 制作无光栅10.33 µm验证片 | **建议进行** |
| 制作带DFB量产的10.33 µm片 | **暂缓** |
| 制作9.17 µm固定腔器件 | **不建议** |
| 直接相信1周期NEGF的绝对效率 | **不建议** |

最终建议：先做**同一Sun层序的宽区校准片 + 可后加工DFB测试区**。
等实际EL/增益峰确认落在10.2–10.8 µm、多周期NEGF问题解决后，
再冻结DFB光栅和量产外延。
