# 8 µm NEGF 校准：偏压、掺杂与 CBO

> 2026-10-22。执行 [[38-8um-Liu-DAU-NEGF验证与负结果]] 中规定的校准链：先回算 Liu 原设计 48 kV/cm，再做 220/240/260 mV 扫描，最后检验低掺杂和 CBO 0.60 eV。

## 1. 校准矩阵

统一设置：

- 材料：In₀.₆Ga₀.₄As/Al₀.₅₈In₀.₄₂As；
- 温度：300 K；
- 横向离散：50 meV；
- 横向/轴向能量窗：500/550 meV；
- 电子-电子散射：开启；
- 合金散射强度：1.0；
- GF/电流收敛判据：1×10⁻³；
- 自洽增益读取点：155 meV。

## 2. 偏压扫描说明了什么

启用电子-电子散射后，模型没有恢复已有器件的 1.4 kA/cm² 阈值，也没有让自洽增益转正。

| 趋势 | 观察 |
|---|---|
| 220 → 295 mV | 电流 7.0 → 9.4 kA/cm² |
| 220 → 295 mV | 电子温度 1118 → 1466 K |
| 全部偏压 | 155 meV 自洽增益为 −17 至 −18 cm⁻¹ |
| 全部偏压 | L-I 输出为 0 |

结论：问题不只是偏压。即使降低到 220 mV，模型仍远未进入激射状态。

## 3. 降低掺杂的强证据

保持 240 mV、层序、CBO 和散射不变，只把片密度从 2.63×10¹¹ 降到 7.04×10¹⁰ cm⁻²：

| 量 | 高掺杂 | 低掺杂 | 变化 |
|---|---:|---:|---:|
| 电流 | 8034 A/cm² | 2316 A/cm² | −71% |
| 电子温度 | 1192 K | 1203 K | 基本不变 |
| FGR155 | +15.82 | +3.25 | 下降 |
| 自洽155 | −17.20 | **−4.72** | 改善 12.5 cm⁻¹ |
| 模态增益 | −8.60 | −2.36 | 仍低于损耗 5 |

意义：

1. 高片密度会显著放大模型电流和热回填；
2. 降低片密度使自洽损耗缩小到约 −5 cm⁻¹，已经进入“可继续调参”的范围；
3. 电子温度仍约 1200 K，说明高场电子加热并不能仅由掺杂修复。

## 4. CBO 0.60 eV 对照

把势垒 CBO 从 0.72 降到 0.60 eV：

- 基态微带从 123.5 meV 移到 112.9 meV；
- 轴向微带数从 16 增到 18；
- 出现“能量窗大于阱深、可能包含连续态”的警告；
- 电流升到 3216 A/cm²；
- 电子温度升到 1840 K；
- 155 meV 自洽增益仍为 −4.94 cm⁻¹。

结论：0.60 eV 不是有效修正，反而破坏上态束缚并增加连续态；当前应保留数据库给出的约 0.72 eV。

## 5. 当前剩余的核心问题

FGR 正、自洽负的系统性分裂仍在。已排除：

| 假设 | 结论 |
|---|---|
| 输入语法或未收敛 | 排除 |
| 仅偏压过高 | 部分改善，但不是根因 |
| 仅掺杂过高 | 大幅改善电流和自洽损耗，但未转正 |
| CBO 0.60 更准确 | 排除 |
| 8 µm 附近没有态或 FGR 峰 | 排除 |

剩余优先级：

1. 模型所用 CBO/有效质量/散射参数与原文计算模型仍可能系统不同；
2. NEGF 的 1-period、1-period coherence 与真实多周期输运可能存在边界差；
3. 原文层序的后续周期、掺杂和测试条件需要再次核对；
4. 自洽增益计算本身需要通过一个同材料、同波长的已知 8–9 µm 器件做二次校准。

## 6. 下一步计算建议

不建议继续在 8 µm 结构上盲扫。建议先构造一个“双层校准”：

1. 用 Liu 7.4 µm 结构，低掺杂、240–260 mV 找到第一组正自洽增益；
2. 若仍然全负，改用一个官方 NEGF 已知可激射的 InGaAs/InAlAs 中红外结构与当前设置交叉验证；
3. 只有在自洽路径能复现一个已知器件后，才回到 8 µm 的 CBO、层厚和掺杂联合优化。

当前参数保留：

```text
结构：Liu 2022 原始 22 层
偏压：240 mV
片密度：7.0e10 cm^-2
CBO：0.72 eV
电子-电子散射：yes
合金散射：1.0
```

它是目前最接近“有可持续增益”的模型点，但模态增益仍为 **−2.36 cm⁻¹**，不能称为可激射设计。
