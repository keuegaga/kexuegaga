# 项目结构与文件类型

## 典型项目目录

- 一个仿真项目的所有文件共用同一个文件名（用户自取），仅扩展名不同（Workbook03 引言）。
- 用户创建的输入文件：`name.layer`、`name.gain`、`name.sol`、`name.plt`。
- 软件自动生成的次级文件：`name.mater`、`name.doping`、`name.geo`、`name.mplt`、`name.msh`、`name.out_#`、`name.std_#`、`name.log`（PICS3D 另加 `name.vcsel`、`name.rtd`、`name.stw` 等）。
- 处理顺序：`.layer` → 处理生成 `.geo` / `.mater` / `.doping` / `.mplt` → `.geo` → 生成网格 `.msh` → `.sol` 求解 → `.out_#` / `.std_#` → `.plt` / CrosslightView 绘图。

## 文件类型速查

| 扩展名 | 含义 | 谁生成 | 谁读取 | 详见 |
|---|---|---|---|---|
| .layer | 器件结构（分层/列定义） | LayerBuilder / Layer3d / setuplayer | layer.exe（处理生成 .geo 等） | [[Layer3d]] |
| .geo | 几何/网格定义 | 处理 .layer 生成，或 GeoEditor | 网格生成器 / 求解器 | [[GeoEditor]] |
| .mater | 材料参数 | 处理 .layer 自动生成，可用户编辑 | 求解器 / gain 程序 | [[mater_define]] |
| .doping | 掺杂分布 | 处理 .layer 生成 | .sol（include）→ 求解器 | - |
| .msh | 有限元网格 | 网格生成器（处理 .geo） | 求解器 | - |
| .sol | 求解设置（材料+偏置+条件） | GUI（SimuCenter 向导）或用户 | 求解器 | [[sol文件|.sol文件]] |
| .plt | 绘图设置 | GUI 或用户 | GNUPLOT / CrosslightView | [[plt文件|.plt文件]] |
| .std | 结果数据（数值后缀 .std_#） | 求解器 | CrosslightView | [[std文件|.std文件]] |
| .dat | XY 两列数据 | 用户/脚本 | CrosslightView | - |
| .gain | 增益谱/自发辐射/子带预览 | 用户（可从 .mater 生成模板） | gain 程序（LASTIP/PICS3D） | [[gain文件|.gain文件]] |

> 注：官方手册中的结构输入文件是 `.layer`、材料文件是 `.mater`；全手册未出现 `.str` / `.mtrl` 扩展名（2024 版 manual.pdf 全文检索 0 次）。
