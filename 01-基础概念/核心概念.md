# 核心概念

## 仿真对象

Crosslight 器件仿真求解半导体器件中的：电势与电场、电子/空穴浓度与电流、复合（SRH/辐射/俄歇）、量子阱子带与增益、光场分布与输出功率。

## 物理与数值基础

- 基于漂移-扩散模型求解 Poisson 方程与电子/空穴连续性方程；
- 默认基本求解变量为电势与准费米能级；高阻/电流阻挡结构可 `change_variable=yes` 切到载流子浓度（manual §4.7）；
- 有限元网格：物理量在网格点之间变化，网格必须能采样剧变区（见 [[07-故障排查/网格划分误差]]）；
- Newton 迭代：偏置小变化 → 解小变化；步长、容差、阻尼见 [[05-API与命令/核心参数]]。

## 偏置与收敛

- 高阻器件用电压偏置、低阻器件用电流偏置；激光器激射后只能用电流偏置（manual §4.1）；
- 标准正偏流程：equilibrium → 电压扫到内建电压 80-90% → 校验 KCL → 电流偏置到目标；
- PICS3D 激光器需以 `auto_finish=rtgain` 完成模式初始化（manual §4.2）。

## 光与增益

- 增益谱/透明载流子密度/激射阈值：正式仿真前用 `.gain` 预览（见 [[05-API与命令/gain文件|.gain 文件]]）；
- PICS3D 特有：RTG（往返增益方程）用于纵模与光子密度初始化、LSHB（纵向空间烧孔）。

```text
.layer → .geo → .msh → .sol（+ .mater/.doping）→ .out_# / .std_# / .log → .plt / CrosslightView
```
