# 核心参数

第一批只收录最常用的 8 个参数，每条按六要素：含义 / 类型 / 可选值 / 默认值 / 约束 / 相关错误。手册未明示的默认值标注「手册未给出，待验证」，不猜测。

## bias 变量（voltage_1 / current_1）

- 含义：施加在某个电极上的偏置量。`voltage_1` / `current_1` 中的数字是电极编号，如 `voltage_2` 指电极 2 的电压（manual 第3章 §3.3）。
- 类型：float（电压单位 V；电流单位 A）
- 可选值：`voltage_1..N` / `current_1..N`（对应接触/电极编号）
- 默认值：无（偏置必须显式给定）
- 约束：高阻器件用电压偏置，低阻器件用电流偏置（§4.1）；激光器激射后载流子与准费米能级被受激复合钳位，只能用电流偏置（§4.1）；PICS3D 引入光子耦合前需电流扫描 + `auto_finish=rtgain`（§4.2）；多电极器件 p 侧电流按惯例为负。
- 相关错误：电压远高于开启电压 → 指数电流变化导致不收敛；激射后用电压偏置 → 钳位导致无解；总电流极小时用电流偏置 → 数值精度不足、KCL 违反（§4.1）。

## scan（偏置扫描语句）

- 含义：从上一个解出发，逐步改变偏置变量，为 Newton 求解提供连续初始猜测。
- 类型：语句，主要参数 `var` / `value_to` / `init_step` / `min_step` / `max_step` / `print_step` / `auto_finish` / `auto_until`
- 可选值：`var=voltage_1` / `current_1` / `bandgap_reduction` 等任意可扫变量；可加 `var2=time value2_to=1.0` 做慢瞬态
- 默认值：示例常见 `init_step=1e-3`、`min_step=1e-5`、`max_step=0.5`；具体默认手册未集中给出，待验证
- 约束：每步变化要小（「偏置的小变化 → 解的小变化」）；热失控时用 `max_step` 限步（§4.4）；高阻/极化结构可改用慢瞬态（§4.8）；高阻结构可加大初始步长避开低偏难题（§4.9）。
- 相关错误：步长过大 → 不收敛；`min_step` 与热模型 `max_temp_incr` 冲突 → 仿真失败（§4.4）。

## auto_finish / auto2_finish（扫描终止条件）

- 含义：当被监视变量达到指定条件时结束当前扫描。
- 类型：string（被监视变量名），配合 `auto_until`（float）与 `auto_condition`（string）
- 可选值：`current_1` / `voltage_1` / `rtgain`（PICS3D 激光模式专属）等；`auto_condition=above / below / within`
- 默认值：无
- 约束：PICS3D 中计算 RTG 前的扫描必须以 `auto_finish=rtgain` 终止（§4.2）；RTG 终止值取略高于透明密度、且小于 1.0（避免进入激射阈值）；VCSEL 低阈值时可合并电压段与 RTG 初始化，用 `auto2_finish` 加电流下限（§4.2）。
- 相关错误：RTG 终止值太高 → 初始光子猜测不准；太低 → 漏掉关键纵模（§4.2）。

## temperature temp=

- 含义：仿真温度。等温仿真直接用；热仿真与工艺语句（如 `diffuse`）也用它。
- 类型：float（单位 K）
- 可选值：任意正温度；示例均为 300 K（`temp=300` / `temp= 0.3000E+03`）
- 默认值：示例 300 K；全局默认手册未明示，待验证
- 约束：材料参数随温度变化时用 `variation=function` 或 `table` 语法（附录B）；自热模型需 `heat_flow`；温度上升过快会使下一步初始猜测失效。
- 相关错误：温度与材料宏数据不一致 → 带隙/增益偏差；热失控 → 不收敛（§4.4）。

## 网格密度（column mesh_num / layer n / put_mesh / double_mesh / regrid）

- 含义：有限元网格点的数量与分布（网格是仿真的分辨率）。
- 类型：integer（`mesh_num`、`n`、`put_mesh number`）+ float（`ratio`）
- 可选值：`.layer` 用 `mesh_num`（列）与 `n`（每层）；`.geo` 用 `put_mesh`（每条边 `number`/`ratio`）；局部 `double_mesh` / `half_mesh`；自动 `regrid`
- 默认值：无统一默认；setuplayer 交互建议总网格点 20–40、最大间距 0.1–0.5 µm（§3.3.1）；Workbook03 建议最大平均间距约为最大层厚的 20%
- 约束：总点数约等于 Σ(mesh_num) × Σ(n)（§3.3.2）；剧变区（异质结/肖特基/隧穿/电流拥挤/量子阱/光模峰）加密，低阻区（金属、重掺杂接触）减密（§4.5/4.6）。
- 相关错误：过粗网格 → 剧变区欠采样、不收敛（§4.5）；低阻区过细 → ΔV→0，电流控制数值失稳（§4.6）。

## 材料参数文件与宏（include file= / load_macro / get_active_layer / use_macrofile）

- 含义：材料定义的来源与加载方式。
- 类型：string（文件名 / 宏名）
- 可选值：`include file=test1.mater`（.sol/.gain 引入材料与掺杂）；`load_macro name=xxx mater=N`（被动宏，小写）；`get_active_layer`（主动宏，混合大小写，管量子阱子带）；`use_macrofile macro1=xxx.mac`（自定义宏文件）
- 默认值：处理 `.layer` 自动生成 `name.mater`；默认宏库 `crosslight.mac` / `more.mac`
- 约束：绝不修改默认宏文件（影响所有仿真，§3.5）；自定义用 `use_macrofile` 或 `load_macro` 后重发参数语句覆盖（后发覆盖先发）；单位：长度 µm、能带 eV、掺杂 m^-3、迁移率 m²/(V·s)；`use_macrofile` 必须单条语句写多个 `macroN=`，拆成多条是错的（附录B）。
- 相关错误：宏选错材料系/晶格匹配 → 静默算错（§22.2）；cm^-3 与 m^-3 混用 → 结果异常。

## Newton 求解容差与迭代（newton_par var_tol / damping_step / max_iter）

- 含义：Newton 迭代的收敛判据、阻尼与迭代上限。
- 类型：float（`var_tol`、`damping_step`）/ integer（`max_iter`）
- 可选值：`newton_par damping_step=... max_iter=... var_tol=... use_sor`；基本变量切换用 `change_variable`（Fermi 能级 ↔ 载流子浓度，§4.7）
- 默认值：`var_tol` 手册未给出（待验证）；教程示例 `damping_step=1~5`、`max_iter=100`（§3.3 示例 .sol）
- 约束：收敛困难时可放宽 `var_tol`（ch23 建议）；高阻/电流阻挡结构可切到载流子浓度变量（§4.7），但注意少子精度与 Jacobian 数值溢出风险。
- 相关错误：迭代不收敛 → 先检查初始猜测/网格/偏置策略；容差过严会把可接受解判成发散（ch23）。

## 增益预览（gain_wavel wavel_range / conc_range / curve_number）

- 含义：正式仿真前预览材料增益谱、自发辐射谱、透明载流子密度等。
- 类型：float 范围（波长 µm、载流子密度 m^-3）+ integer（`curve_number`、`data_point`）
- 可选值：`gain_wavel wavel_range=[0.80 0.84] conc_range=[0.1e24 0.5e26] curve_number=20` 等
- 默认值：无；范围由用户按材料/波长设定
- 约束：`include file=xxx.mater` 提供材料参数；PICS3D 必须先生成 `.gain` 文件再预览（Workbook03）；确认目标波长处增益为正、透明载流子密度合理后再跑正式仿真。
- 相关错误：增益为负 → 载流子密度不足或波长偏离增益峰；`.gain` 缺失时右键 `.mater` 生成模板。
