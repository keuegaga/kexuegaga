# 命令索引

Crosslight 的操作分散在 GUI 菜单与命令行两处，下表两者都记。2024 版统一图形界面为 SimuCenter（旧版叫 SimuLASTIP / SimuAPSYS / SimuPICS3D），命令行程序位于 `C:\crosslig\pics3d\`。

| 操作 | GUI 路径 | 命令行/文件 | 详见 |
|---|---|---|---|
| 打开项目 | File → Open Project | 加载 `.sol` / `.gain` / `.spj`（manual 3.1） | [[01-基础概念/项目结构与文件类型]] |
| 定义结构 | LayerBuilder / Layer3d 对话框 | `.layer` 文件（处理生成 `.geo`/`.mater`/`.doping`） | [[Layer3d]] |
| 编辑几何 | GeoEditor | `.geo` 文件 | [[GeoEditor]] |
| 材料定义 | 材料/宏对话框 | `.mater` 文件（`load_macro` / `get_active_layer`） | [[mater_define]] |
| 处理结构 | 右键 `.layer` → Process | `layer.exe xxx.layer` | [[标准工作流]] |
| 生成网格 | 右键 `.geo` → Generate Mesh | `pics3d.exe xxx.geo` | [[标准工作流]] |
| 增益预览 | 右键 `.gain` → Process Gain | `pics3d.exe xxx.gain` | [[gain文件|.gain文件]] |
| 运行仿真 | SimuCenter 运行按钮 | `pics3d.exe xxx.sol > xxx.log` | [[标准工作流]] |
| 查看结果 | CrosslightView | `.std` / `.plt`（psplot） | [[std文件|.std文件]]、[[CrosslightView]] |

> 注：官方手册中结构输入文件为 `.layer`、材料文件为 `.mater`（2024 版全文无 `.str` / `.mtrl`），此处按官方命名。

## SimuCenter 快捷键（安装目录 shortcuts.txt）

| 快捷键 | 功能 | 快捷键 | 功能 |
|---|---|---|---|
| Ctrl+L | Process Layer | Ctrl+G | Generate Mesh |
| Alt+P | Process Gain | Alt+S | Simulate |
| Ctrl+M | View Mesh | Alt+R | View Result |
| Alt+D | Open GeoEditor | Alt+3 | Open Layer3d |
| Alt+L | Open LayerBuilder | Ctrl+W | Show Wizard |
