# Crosslight PICS3D 知识库（GaN 激光器）

本仓库既是 Obsidian vault，也是 Git 仓库，供 Crosslight PICS3D/APSYS GaN 激光器仿真相关的笔记、资料和项目文件使用。

## 目录

- `books/`：参考书籍与资料
- `manual.pdf`：Crosslight 手册
- `PICS3D-GaN Lasers.md` 等：Obsidian 笔记（vault 根目录）

## 使用

- Obsidian：「打开文件夹作为 vault」选择本目录
- Git：本目录已初始化，直接 `git add` / `git commit`
