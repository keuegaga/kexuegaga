# Crosslight 安装

## 系统要求

来源：manual.pdf 第 2.1 节。

最低配置：

- 64 位 Intel Pentium 4（或同级）CPU
- 64 位 Microsoft Windows 7
- 1 GB 内存
- 4 GB 可用磁盘空间

推荐配置：

- Intel i7（或同级）CPU
- 64 位 Microsoft Windows 10
- 8 GB 内存
- 4 GB 可用磁盘空间

## 安装步骤

来源：manual.pdf 第 2.2 节。

1. 运行安装程序，按向导完成安装；安装后从开始菜单启动。
2. 以随安装介质/下载包提供的版本专属说明为准，其中包含必须单独安装的 Microsoft 可再发行 DLL 列表（可能已被其他程序装过）。
3. 不要把多个 Crosslight 软件包装进同一目录，否则不同版本的文件会互相覆盖、产生版本错误；尽量使用默认安装目录。
4. 加密狗（dongle）授权：安装时同步安装 dongle 驱动（随安装包提供）。
5. 远程授权：确保电脑可访问互联网，并正确配置防火墙以访问 Crosslight 授权服务器。

## 附加软件

来源：manual.pdf 第 2.3 节。

- GNUPLOT：Crosslight 默认绘图程序（https://www.gnuplot.info/），按所选绘图设备输出 Postscript 或 PDF。
- PDF 查看：现代浏览器原生支持；推荐 Adobe Acrobat Reader（https://get.adobe.com/reader/）。
- Postscript 查看：GSView + Ghostscript（64 位系统应使用 64 位版本；GSView 已停止开发），或 Okular、Evince。
- CrosslightView：无需额外绘图软件即可查看仿真结果（推荐）。

## 安装后验证

1. 从开始菜单启动 `PICS3D-2024\SimuCenter`（本机安装目录：`C:\Program Files\Crosslight Software\pics3d_2024`）。
2. File → Open Project，打开自带示例项目（步骤见 [[06-案例/最小可运行案例]]）。
3. 依次执行：`.layer` → Process（生成 `.geo`/`.mater`/`.doping`）→ `.geo` → Generate Mesh → `.sol` → Simulate。
4. 求解器正常结束并生成 `.out_#` / `.std_#` 文件，即安装成功。

## 常见问题

- 启动/运行失败的最常见三种原因（manual.pdf 3.1 节）：缺少可再发行库；许可证错误（license 文件或 dongle）；防火墙未放行授权服务器。
- 详细排查见 [[07-故障排查/常见错误索引]]。
