# 边界条件、网格与数值技巧

> 目标：让仿真结果"可信"——没有边界伪态污染、网格足够细、本征态够多、物理模型选对。

## 1. 边界条件：QCL 必须用 Dirichlet

### 1.1 为什么不能周期边界

外加电场使能带沿生长方向倾斜，**周期边界条件与倾斜能带不相容**——左右边界势能不一样，波函数无法满足周期性。官方明确说：

> periodic boundary conditions for the Schrödinger and Poisson equation do not make sense because of the application of an electric field.

正确写法：

```python
quantum{
    region{
        ...
        boundary{ x = dirichlet }
    }
}
```

### 1.2 Dirichlet 的代价与对策

波函数在边界被迫为零 → 边界附近出现**人为的伪态（artificial states）**，能量和波函数都不可信。

对策（官方建议）：

> 算 **3 或 5 个周期**，取**中间周期**的能级与波函数用于设计判断。中间态波函数在边界已衰减为零，不受边界影响。

Page2001 示例就是这么干的：手写约 3 个周期，量子区覆盖全器件，分析时看中间周期。

## 2. 网格设置

### 2.1 默认起点

- QCL 教程全部用 **0.1 nm** 间距（GaAs 单胞 0.565 nm，0.1 nm 足够分辨）
- 界面（每个层边界）处必须放 `line{ pos = 边界坐标 spacing = ... }`

```python
grid{
    xgrid{
        line{ pos = 0.0  spacing = 0.1 }
        line{ pos = 4.6  spacing = 0.1 }
        ...
    }
}
```

### 2.2 收敛性检查

- 跑一个设计后，把网格加密到 0.05 nm（或减到 0.2 nm），比较关键跃迁能量
- 变化 < 1 meV 即认为收敛
- THz QCL（能量只有 ~10 meV 量级）对网格更敏感，务必检查

## 3. 本征态数量（num_ev）

- 覆盖多少个周期，就大致需要 3–4 倍于周期数的态（每周期至少注入态+3 个激光相关态）
- Page2001（3 周期）：20；Capasso（5 阱超晶格）：40；Andrews THz（3 周期）：30
- **宁可多算**：`num_ev` 只是计算成本，不足时中间周期的关键态可能缺失
- 识别态时用 `output_wavefunctions` 输出 |ψ|²，按空间分布归属到具体周期

## 4. 电场与参考电势

- 恒定电场法：`strength = -48.5e5`（V/m）；**1 kV/cm = 1e5 V/m**
- `reference_potential` 把网格最左端电势设为给定值，作用是**整体平移能带**，让结果便于与文献/nextnano³ 对比，不影响能级差
- 接触偏压法：电场 ≈ 电压差 / 两接触间距离，注意坐标长度单位换算（nm → m）
- 偏置扫描：每周期偏压一般 30–60 mV（中红外）或几 mV~十几 mV（THz），THz 模板里有 `$BIASSWEEP` 开关

## 5. 泊松自洽（flow-scheme 20 vs 21）

nextnano³ 的说法，nextnano++ 的 `run{}` 等价：

| 模式 | 做什么 | 适用 |
|---|---|---|
| 只解 quantum（flow-scheme 21） | 施加电场 + 解 Schrödinger，不做泊松自洽 | 无掺杂的能级设计第一步 |
| quantum + poisson（flow-scheme 20） | 自洽求解（掺杂、载流子再分布） | 有掺杂、需要能带弯曲时 |

注意：**自洽 ≠ 自动考虑粒子数反转**。QCL 的输运/反转必须用 NEGF 才严谨；泊松自洽只是让能带更真实。

无掺杂设计中常用 `no_density = yes`，避免量子态密度反哺泊松造成混淆。

## 6. 其他数值习惯

- 结构必须从背景（`everywhere`）开始，再把每层 `region` 叠上去；层坐标首尾相接、不重叠
- 修改材料参数走 `database{}`，不要改安装目录下的材料库文件
- 1D 仿真先跑通，再考虑 2D/3D（侧向波导、热效应）
- 保存每个版本的输入文件（文件名带日期/版本），便于追溯调参历史——Obsidian 仓库里可以同步放输入文件副本

## 7. 快速排查表

| 症状 | 可能原因 |
|---|---|
| 边界处出现异常紧密的态 | 忘记 Dirichlet，或直接用了边界态 |
| 能级对不上文献 | 带阶没校准、温度不对、网格太粗、num_ev 不够 |
| 波函数漏了中间周期 | num_ev 太少 |
| 能带整体抬高/压低 | reference_potential 与文献不一致（不影响 ΔE） |
| 层序报错 | region 坐标不连续或重叠 |
