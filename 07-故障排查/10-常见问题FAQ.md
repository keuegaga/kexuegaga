# 常见问题 FAQ

## Q1：计算波长和实验/论文对不上？

按顺序排查：

1. **带阶**：是否按论文校准了 CBO？（[[06-材料体系与能带参数]]）
2. **温度**：是否用了论文的器件温度（77 K / 300 K）？
3. **电场**：强度与方向符号是否正确？参考电势只平移不改变 ΔE
4. **模型**：非抛物性材料（InGaAs）用单带会偏，换 k.p 试试
5. **网格**：加密到 0.05 nm 验证收敛
6. **应变**：应变体系是否设置了正确衬底？
7. **态认错**：确认选的是激光跃迁的两态，不是注入/去填充态

## Q2：怎么把片掺杂密度（cm⁻²）换成体浓度（cm⁻³）？

$$n_{vol} = \frac{n_{sheet}}{d_{doping}\,[\mathrm{cm}]}$$

示例：3.8×10¹¹ cm⁻² 掺在 9.8 nm 层内 → 3.8e11 / (9.8e-7) ≈ 3.9×10¹⁷ cm⁻³。

nextnano++ 中：

```python
doping{ constant{ name = "fully-ionized" conc = 3.9e17 } }
```

## Q3：电场单位总搞混

- nextnano++ 中电场单位是 **V/m**
- 1 kV/cm = 10⁵ V/m = 1e5 V/m
- 负号代表电场沿 -x（与坐标正方向相反），常见于 QCL 教程

## Q4：为什么边界上出现奇怪的波函数？

Dirichlet 边界条件造成的**边界伪态**，正常现象。对策：算 3–5 周期，只看中间周期（[[08-边界条件-网格-数值技巧]]）。

## Q5：能不能用周期边界？

**有外加电场时不能**。电场使能带倾斜，周期边界不自洽。无电场、无掺杂的均匀超晶格才可以用 `periodic{ x = yes }`。

## Q6：为什么看不到注入态/某个能级？

- `num_ev` 不够 → 增大
- 量子区范围不对 → 确认覆盖所有周期
- 态存在但能量太高/太低 → 检查波函数文件里所有态的空间分布，重新识别

## Q7：自洽计算不收敛或结果异常？

- 先做无掺杂、无自洽的能级设计，再逐步加复杂度
- 掺杂浓度过高导致能带弯曲过大 → 减掺杂或重设计
- 检查 `no_density = yes` 是否误加在需要自洽的区

## Q8：nextnano³ 和 nextnano++ 结果差一点？

正常，二者默认材料参数可能不同（如带阶基准）。官方 Page2001 示例特意用 `reference_potential = 2.1315` 和 bowing 校准让两者对齐。以你自己验证过的参数为准。

## Q9：z 矩阵元 vs p 矩阵元，看哪个？

- 非对角跃迁元两者等价（同一 f），可互查
- 对角元 ⟨i|z|i⟩ 依赖坐标原点，无物理意义
- k.p 计算的"振荡强度"需要手动指定质量，参考官方教程做法

## Q10：什么时候需要 nextnano.NEGF？

当要回答以下问题时：

- 这个设计在多少电压下出光？
- I-V / J-V 特性是什么？
- 增益谱峰值多少 cm⁻¹？
- 粒子数反转能否建立（τ₃ vs τ₂、散射机制影响）？

能级设计（阶段 0–5）用 nextnano++ 就够。见 [[12-进阶-NEGF输运与增益优化]]。

## Q11：怎么让 nextnanomat 显示更丰富的输出？

在 `output{}` 中开启，例如：

```python
output{
    material_parameters{
        charge_carrier_masses{ boxes = yes }
    }
}
```

## Q12：我想扫描厚度/合金，手工改太累？

- 用 nextnano 参数化 `$变量` + nextnanomat Template 功能
- 或直接上 nextnanoevo（Python 自动优化，[[12-进阶-NEGF输运与增益优化]]）
