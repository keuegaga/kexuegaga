# QCL 设计流程 Checklist

> 从"有个目标波长"到"验证过的仿真设计"，一条龙清单。把每条都勾掉，你的第一个 QCL 设计就完成了。

## 阶段 0：目标定义

- [ ] 确定目标波长 λ（或光子能量 E = 1240/λ[µm] meV）
- [ ] 确定工作温度（300 K 中红外 / 4–100 K THz）
- [ ] 确定材料体系（见 [[06-材料体系与能带参数]]）
- [ ] 查文献找一个同体系、同量级波长的参考 QCL（见 [[11-文献库]]）

## 阶段 1：拿到/设计周期层序

- [ ] 从文献表格提取每层厚度（阱/垒，nm）与合金组分
- [ ] 记录论文的导带带阶 CBO（如 390 meV）
- [ ] 记录工作电场或每周期偏压（如 -48.5 kV/cm）
- [ ] 记录掺杂（片密度 n_sheet cm⁻² 与掺杂层位置）
- [ ] 算总周期长（用于网格与量子区设置）

## 阶段 2：搭第一个 nextnano++ 输入文件

- [ ] 复制模板：`templates/QCL输入文件模板.nnp`
- [ ] 写 `global`：simulate1D、衬底、温度
- [ ] 写 `structure`：背景材料 + 逐层 region（坐标连续）
- [ ] 写 `grid`：每层边界放 line，间距 0.1 nm
- [ ] 选加电场方式（`poisson.electric_field` 或 `contacts` 偏压）
- [ ] 写 `quantum`：Dirichlet、num_ev（3 周期 ≥ 20）、输出波函数 + 矩阵元
- [ ] 若论文 CBO 与默认不同，在 `database` 校准带阶
- [ ] 第一轮：不掺杂、不泊松自洽（`run{ quantum{} }`）

## 阶段 3：跑通并核对能级

- [ ] 导带边呈预期斜率（电场正确）
- [ ] 波函数输出无异常（中间周期态干净）
- [ ] 在能带图上识别：注入态、上激光态 |3⟩、下激光态 |2⟩、基态 |1⟩
- [ ] 核对 ΔE₃₂：|ΔE − 目标| < 5 meV（先粗后细）
- [ ] 核对偶极矩 z₃₂ ≥ 1 nm
- [ ] 注入对准：|E_injector − E₃| < kT
- [ ] 去填充通道成立（共振或 LO 声子）

## 阶段 4：迭代调参（设计核心工作）

调参规则：

| 想达到 | 调什么 |
|---|---|
| 波长变长（ΔE 变小） | 加宽发射阱 |
| 波长变短 | 收窄发射阱 / 提高垒的 Al 组分 |
| 增大 z₃₂ | 调层序让 |3⟩、|2⟩ 波函数重叠更好 |
| 改善注入 | 调注入区层厚，使注入态与 |3⟩ 共振 |
| 改善去填充 | 调 ΔE₂₁ ≈ LO 声子 / 隧穿共振层 |

- [ ] 每次只改一个参数，记录 ΔE、z、注入对准的变化（做表）
- [ ] 网格收敛性检查（0.1 → 0.05 nm 试算）
- [ ] 关键结论用"3 周期取中间"规则验证

## 阶段 5：加掺杂与自洽

- [ ] 按论文放掺杂层（体浓度 = 片密度/层厚）
- [ ] `run{ poisson{} quantum{} }` 开自洽
- [ ] 检查掺杂引起的能带弯曲是否破坏对准（严重则调掺杂或结构）

## 阶段 6：增益与输运（进阶）

- [ ] 用 nextnano.NEGF 算偏置点上的增益谱 G(E)
- [ ] 看峰值增益对应能量 ≈ 目标光子能量
- [ ] 扫描偏置，找增益最大工作点
- [ ] （可选）用 nextnanoevo 优化厚度（见 [[12-进阶-NEGF输运与增益优化]]）

## 阶段 7：记录与归档

- [ ] 把最终输入文件与参数表存进仓库（可建 `designs/` 文件夹）
- [ ] 记录：层序、CBO、电场、温度、掺杂、ΔE、z₃₂、增益
- [ ] 写一篇设计笔记，链接文献与本次迭代过程
