===== PDF page 5 =====
5
Build a 3D structure
#  Mesh define #
A line starting from “#” is a line of comment
line x loc=0.0 tag=lft spacing=0.04
line x loc=@gatelen/2   spacing=0.02
line x loc=@gatelen/2+0.2 tag=rht spacing=0.04
line y loc=0.0 tag=top spacing=0.01
line y loc=0.1 spacing=0.03
line y loc=0.5 spacing=0.05
line y loc=1.0 spacing=0.1
line y loc=2. tag=bot spacing=0.3 
“line” command is used to specify a flag point in x or y direction. The point can have a “tag” to be cited 
in other commands. Between these flag points, mesh points will be inserted with density 
controlled by “spacing”. Smaller “spacing” means more mesh points.  In addition, “@gatelen” is a 
variable whose value must be specified before its citation.
After flag points in x and y direction are defined, they will form a rectangle 2D mesh  like a 2D matrix 
where each mesh point acts as a matrix element.
This is content of xyplane1.in which is same as 
xyplane2.in, xyplane3.in, xyplane4.in and xyplane5.in

“elim” command is used to eliminate mesh points in x or y direction ( x.dir or y.dir). These mesh

8
Build a 3D structure
begin_zst
z_structure uniform_zseg_from=0.0   uniform_zseg_to=0.0 zplanes=1  zseg_num=1
z_structure uniform_zseg_from=0.333 uniform_zseg_to=0.333 zplanes=1  zseg_num=2
z_structure uniform_zseg_from=0.389  uniform_zseg_to=0.389 zplanes=1  zseg_num=3
z_structure uniform_zseg_from=0.444 uniform_zseg_to=0.444 zplanes=1  zseg_num=4
z_structure uniform_zseg_from=0.5  uniform_zseg_to=0.5 zplanes=1  zseg_num=5
z_structure uniform_zseg_from=0.501 uniform_zseg_to=0.501 zplanes=1  zseg_num=6
z_structure uniform_zseg_from=2.5  uniform_zseg_to=2.5 zplanes=1  zseg_num=7
“z_structure” command is used to specify position of a x-y plane and is supported by both 
Csuprem and APSYS  softwares.  x-y planes are numbered by “zseg_num” and located by 
“uniform_zseg_from” and “uniform_zseg_to”. “zplanes” tells how many times this x-y plane 
will be repeated before next x-y plane.  But we fix “zplanes” equals 1 in Csuprem to make an 
uniform segment between 2 x-y planes, which helps preventing abnormal crash when doing 
simulation of “oxidation” processing.
This is content of zmesh.zst

Simplified processes
Steps
1. 3D-STI
2. deposit gate oxide

3D device simulation by Apsys
② Setup for bias scan
newton_par damping_step=5. max_iter=100 print_flag=3
“newton_par” command specifies a lot of parameters for Newton iteration which is a mainly mathematical method 
applied in Apsys software. This command must be put before “equilibrium”a n d  “scan” commands. For detail 
explain, please refer to its help text and ask technical member in Crosslight.
equilibrium outfile_label=biaslab_0 
“equilibirum” tells simulator calculate physical properties of the device at equilibrium state, including potential, 
band diagram, etc. 
newton_par damping_step=1. print_flag=3
“newton_par” can be used before different “equilibrium”o r  “scan” commands to make different settings of Newton 
iteration.
start_loop symbol=%olab value_from=1 value_to=2
integer_func symbol=%ilab value_from=0 value_to=1
real_func symbol=%gbias value_from=0.5 value_to=1.0
Here, “start_loop” is used to loop a series of “scan” commands. “symbol” variables specified in “start_loop”, 
“integer_func”a n d  “real_func” commands will be changed simultaneously.

===== PDF page 42 =====
42
3D device simulation by Apsys
② Setup for bias scan
scan var=%Vg value_to=%gbias init_step= 0.5000E-01 infile_label=biaslab_%ilab outfile_label=biaslab_%olab
scan var=%Vd value_to= 35.000E+00 scan_label=VDscan_%olab init_step= 0.5000E-01 max_step= 0.4667E+00 &&
auto_finish=incr_current_3 auto_until=5.e-6 auto_condition=above auto2_finish=voltage_3 auto2_until=5. 
auto2_condition=above 
scan var=%Id value_to=250.e-6 print_step=250.e-6 scan_label=IDscan_%olab init_step=0.05e-6 max_step=5.e-6
The upper 3 “scan” commands achieves a function that applies a voltage bias( the first “scan”) at MOSFET gate and 
then applies a voltage( the second “scan”) and current( the third “scan”) bias at MOSFET drain( or source).  Bias 
scan on drain is separated to 2 steps, which is an artifice for mathematical convergence.  The second “scan” will be 
stopped when “auto_finish” condition is satisfied. We can explain the second “scan” as that when current increase 
of contact 3( “incr_current_3”) is “above”“ 3.e-6” or when voltage bias of contact 3( “voltage_3”) is “above”“ 5.”v o l t ,  
this “scan” will be stopped and the third “scan” will be after this. 
The output files from these 3 “scan” commands can be used at post-processing course to get a Vd-Id curve at a 
specified Vg( “%Vg”). Since the loop loops 2 times here, so we can get 2 Vd-Id curves at different Vg in a family 
curve plot.
In addition, the unit of Id( “%Id”) is Ampere since this is a 3D case. For 2D cases, Current unit is A/m2. And, “&&”i s  
used to continue a line. For more detail explain, please refer to help text and ask technical member in Crosslight.
end_loop
