# 最小可运行案例

## 目标

跑通一个最简单的 Crosslight 仿真流程（LASTIP 边发射量子阱激光器示例 gaas10），验证安装。步骤源自 Workbook03 第 2 节（官方教程，2003.04）。

## 环境

- 版本：PICS3D 2024（自 2016 版起已包含 LASTIP 全部功能）
- 操作系统：Windows 10/11（64 位）
- 主界面：SimuCenter（开始菜单 `PICS3D-2024\SimuCenter`；Workbook03 时代的界面叫 SimuLastip）
- 示例根目录：`C:\crosslig`（`lastip_examples\`、`pics3d_examples\`）

## 文件清单

| 文件           | 作用              | 状态  |
| ------------ | --------------- | --- |
| gaas10.layer | 结构定义（量子阱激光器，1D） | ☐   |
| gaas10.gain  | 增益谱预览输入         | ☐   |
| gaas10.sol   | 求解设置（偏置扫描）      | ☐   |
| gaas10.plt   | 输出绘图            | ☐   |

运行后软件会额外生成 `.geo` / `.mater` / `.doping` / `.mplt` / `.msh` / `.out_#` / `.std_#` / `.log`。

## 操作步骤

1. 启动 SimuCenter。
2. File → Open Project，打开示例项目 `C:\crosslig\lastip_examples\A_tutorial\1D_laser\`，选择 `gaas10.sol`（与 Workbook03 第 2 节是同一个示例，含 README_gaas10.txt 和 RUN_gaas10.bat；HTML 教程含结果图：`Program Files\Crosslight Software\pics3d_2024\GUI\HTML\general\lastip_tutorial\A_Tutorial\1D_laser`）。
3. 右键 `gaas10.layer` → Process and generate .geo（生成 `.geo`/`.doping`/`.mater`/`.mplt`）。
4. 右键 `gaas10.geo` → Generate Mesh（生成 `.msh`）；可选：右键 `gaas10.mplt` → View Mesh 检查网格。
5. 右键 `gaas10.gain` → Process Gain File（预览增益谱，确认目标波长 0.83 µm 附近增益为正、透明载流子密度约 1.7e18 cm⁻³）。
6. 右键 `gaas10.sol` → Start Simulation（示例约 2 分钟，视机器而定；进度窗口可保存为 `gaas10.log`）。
7. 右键 `gaas10.plt` → View Results（能带图、光场分布、IV、L-I 等；Workbook 图 6a–6e）。

命令行方式（与 GUI 等价，步骤来自示例自带的 `RUN_gaas10.bat`）：

```bat
cd /d C:\crosslig\lastip_examples\A_tutorial\1D_laser
c:\crosslig\pics3d\Layer gaas10.layer
c:\crosslig\pics3d\pics3d.exe gaas10.gain
c:\crosslig\pics3d\pics3d.exe gaas10.geo
c:\crosslig\pics3d\pics3d.exe gaas10.mplt
c:\crosslig\pics3d\pics3d.exe gaas10.sol > gaas10.log
c:\crosslig\pics3d\pics3d.exe gaas10.plt
```

## 预期输出

- 求解器正常结束；
- 生成 `.out_###` / `.std_###` 文件（`.std` 供 CrosslightView 使用）；
- L-I 曲线阈值电流约 2 mA，发射波长 0.83 µm，光限制因子 Γ≈0.03；
- CrosslightView 能打开 `.std` 并显示。

## 验证清单

- [ ] 无报错
- [ ] 生成 .std
- [ ] 结果合理（IV 曲线形状正常、L-I 阈值约 2 mA）

## 常见失败

- 启动 GUI/仿真失败：多为缺少可再发行库、许可证错误、防火墙 → 见 [[07-故障排查/常见错误索引]]。
- 求解中途退出且没有 `.std`：查看 `gaas10.log` 末尾错误信息（Workbook 提到仿真结束必须以生成 `*.std` 为标志）。
