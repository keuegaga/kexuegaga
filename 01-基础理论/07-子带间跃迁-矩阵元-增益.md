# 子带间跃迁、矩阵元与增益

> 目标：会用 nextnano 输出的矩阵元判断"这个设计能不能出光、波长对不对"。

## 1. 核心物理量

### 1.1 跃迁偶极矩（intersubband dipole moment）

$$M_{fi} = \left| \int \psi_f^*(z)\, z\, \psi_i(z)\, dz \right|$$

- 单位 nm（nextnano 输出 nm 或 Ångström，看文件）
- 决定辐射跃迁强度，增益 ∝ |M|²
- QCL 激光跃迁 |M| 通常要求 **≥ 1 nm** 量级（Page2001 为 1.7 nm）

### 1.2 振荡强度（oscillator strength）

$$f_{fi} = \frac{2m^*}{\hbar^2} (E_f - E_i)\, |M_{fi}|^2$$

或用动量矩阵元 Nfi = ⟨ψf|pz|ψi⟩：

$$f_{fi} = \frac{2}{m^* (E_f - E_i)}\, |N_{fi}|^2$$

- 满足 **f-sum 规则**：Σf ffi = 1（Thomas-Kuhn）
- 无限深阱解析基准：f₂₁ = 256/(27π²) ≈ 0.9607，与阱宽无关

### 1.3 选择定则

- 对称阱中，波函数奇偶性相同 → M = 0（如 |M₁₃| = 0）
- 只有奇偶性相反（Δn 为奇数）的跃迁允许
- 非对称结构（QCL 常态）选择定则放松，但仍可从波函数对称性预判强弱

## 2. 为什么 QCL 需要非对称结构

QCL 周期在电场下倾斜，波函数天然非对称，所以设计自由度更多：

- 上/下激光态可以分别"驻"在结构不同位置
- 靠层序设计让 |3⟩ 与注入态重叠（注入效率），让 |2⟩ 与去填充态重叠（快清空）
- 跃迁矩阵元 z₃₂ 由两层波函数在空间的**重叠与不对称性**决定 → 层序设计就是优化 z₃₂

## 3. nextnano 输出文件怎么读

### 3.1 新版（nextnano++ 当前示例）

`bias_00000/Quantum/` 下：

- `momentum_matrix_elements_quantum_region_Gamma_100.txt`：所有态的动量矩阵元 + 振荡强度 + 跃迁能量
- `transition_energies_quantum_region_Gamma_Gamma.txt`：跃迁能量矩阵
- `overlap_integrals_qr1_Gamma_100.txt`：重叠积分
- `dipole_moment_matrix_elements_qr1_Gamma_100.txt`：偶极矩（z 矩阵元）

### 3.2 旧版（nextnano³ 教程）

`wavefunctions/intraband_pz_cb1_sg1_deg1.txt` / `intraband_z1D_...`：

```
Intersubband dipole moment | <psi_f*|z|psi_i> | [Angstrom]
Oscillator strength
Energy of transition [eV]
m* [m_0]
<psi002*|z|psi001>  18.01673   0.9602799   0.1694912   6.6500001E-02
```

含义：|M₂₁| = 18.02 Å = 1.80 nm，f = 0.960，ΔE = 0.1695 eV，m* = 0.0665 m₀。

### 3.3 常见误区

- **<i|z|i> 依赖坐标原点**（对角元无物理意义），非对角跃迁元才可靠；用 p 矩阵元则都可靠
- 输出里同时有 z 和 p 两种矩阵元，同一跃迁的 f 应一致（可互查）
- 编号 ≠ 物理角色，必须结合波函数空间分布识别"上态/下态/注入态"

## 4. 从矩阵元到增益

### 4.1 材料增益的定性评估

增益峰 ∝ N·|M₃₂|²·(τ₃(1−τ₂/τ₃)…)/线宽。设计阶段可定性比较：

- z₃₂ 大（>1 nm）
- ΔE₃₂ 对准目标光子能量
- 下态寿命 τ₂ 短（声子/隧穿去填充强）
- 上态寿命 τ₃ 长（远离 LO 声子共振、态间散射小）

### 4.2 定量增益：nextnano.NEGF

nextnano.NEGF 直接输出**增益谱**：

```
330mV/Gain/SemiClassical_vs_Energy_[0.0,0.0,1.0].dat
```

格式：光子能量 [meV] 与增益 [cm⁻¹]。设计目标示例（Bai2010 体系）：**在 270 meV 处增益最大**，起点增益 199.49 cm⁻¹。

详见 [[12-进阶-NEGF输运与增益优化]]。

## 5. 设计自检表

- [ ] 激光跃迁的 z 矩阵元 ≥ 1 nm
- [ ] ΔE 与目标波长一致（±2% 内）
- [ ] 跃迁两侧波函数在发射阱内重叠充分
- [ ] 注入态与上态能量差 < kT（300 K 时约 26 meV）
- [ ] 去填充通道明确（共振隧穿 or LO 声子）
