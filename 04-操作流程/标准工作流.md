# 标准工作流

## 目标

跑通一次完整的 Crosslight 器件仿真：结构 → 网格 → 材料 → 求解 → 结果分析。所有产品（LASTIP/APSYS/PICS3D）共用同一条文件管线。

## 文件管线

```text
.layer ──layer.exe──> .geo + .mater + .doping + .mplt
  .geo ──网格生成──> .msh
  .msh + .mater + .doping + .gain ──.sol──> .out_# / .std_# / .log
  .std_# ──.plt / CrosslightView──> 曲线/图形
```

## 步骤

1. **定义结构**：用 LayerBuilder/Layer3d 或 `setuplayer.exe` 生成 `.layer`（分层/列、掺杂、材料宏、网格参数）。
2. **处理结构**：右键 `.layer` → Process（或 `layer.exe xxx.layer`），生成 `.geo`/`.mater`/`.doping`/`.mplt`。
3. **生成网格**：右键 `.geo` → Generate Mesh（或 `pics3d.exe xxx.geo`），生成 `.msh`；可选 `.mplt` 目检网格。
4. **增益预览**（可选但推荐）：`.gain` 预处理，确认目标波长增益为正（见 [[05-API与命令/gain文件|.gain 文件]]）。
5. **求解**：编辑 `.sol`（材料/偏置/数值设置），右键 Simulate（或 `pics3d.exe xxx.sol > xxx.log`）。
6. **分析结果**：`.plt` 绘图或 CrosslightView 打开 `.std_#`。

## 最小 .sol 骨架（来自 gaas10.sol）

```text
begin
use_macrofile macro1=my.mac
load_mesh mesh_inf=gaas10.msh
output sol_outf=gaas10.out
include file=gaas10.doping
include file=gaas10.mater
direct_eigen
init_wave length=400 backg_loss=500. && boundary_type=(2 2 1 1) init_wavel=0.83 mirror_ref=0.32
newton_par damping_step=5. max_iter=100 print_flag=3
equilibrium
scan var=voltage_1 value_to=-2 && init_step=1e-3 max_step=0.1 && auto_finish=current_1 auto_until=1e-3
scan var=current_1 value_to=20. print_step=2. && init_step=1e-3 max_step=0.2
end
```

## 预期结果与验证

- 求解器正常结束，生成 `.out_#` / `.std_#`；
- `.log` 无报错；IV/L-I 曲线形状合理（gaas10 阈值约 2 mA）；
- CrosslightView 能打开 `.std_#` 显示能带、光场、IV、L-I。
